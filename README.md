# Simple SIEM (Security Information & Event Management)

A lightweight web-based Security Information and Event Management (SIEM) dashboard built with PHP, MySQL, CSS, and JavaScript.

## Features
- **Real-Time Security Dashboard**: Visualize log statistics, alert severity levels, and recent events.
- **Log Management**: Ingest, search, filter, and inspect security and system event logs.
- **Alert Rules Engine**: Define rules to trigger automated security alerts based on event patterns.
- **Log Simulator**: Generate mock attack and normal event logs for testing and demonstrations.
- **User Authentication**: Secure role-based login and user management.

## Setup & Installation
1. Import `database.sql` into your MySQL/MariaDB database.
2. Update database credentials in `db.php` if necessary.
3. Start your PHP web server (or run `start.bat` on Windows).
4. Access the web interface via your browser (default: `http://localhost:8000`).
